Code you can read out loud

A hero that runs, jumps with a cooldown, and respawns after touching lava. No boilerplate, no semicolons, no curly braces.

# hero.pawn
speed = 260

when key("right")
    self.x += speed * dt

when pressed("space") and can_use("jump", 0.4)
    self.jump(520)

on touch as who
    if who.has_tag("lava")
        respawn(self)

Install in a minute

No command line, no setup scripts.

  1. Download PawnEngine-Setup.exe with the button above.
  2. Run it. If Windows says “protected your PC”, click More info ▸ Run anyway (the installer isn't code-signed yet).
  3. Pick “Create a Desktop shortcut” and finish. Pawn Engine opens.
  4. Make a project from the main menu. Updates are announced inside the app.
